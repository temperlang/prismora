Prismora

Explore color the way screens and eyes see it. Pick any color, see which screens can show it, and get it in every color space. Prismora is also a library that does this color math from C++, C#, Java, JavaScript, Lua, Python, or Rust.

Pick Color spaces Play Code How it's made

The square shows every lightness and chroma for one hue: gray at the left edge, more vivid to the right. Faded colors exist, but your screen can't show them. Drag across it, or along the rainbow to change the hue.

The same color in every space

A color space is a way to describe colors with numbers. Each one suits a different job. Prismora's numbers run from 0 to 1, with hue in turns (0 to 1) rather than degrees; the CSS column shows each space as CSS writes it.

Play with the API

Edit and run JavaScript using Prismora's Color, Space, HueMethod and Matrix. Hex colors in the output get a swatch. Ctrl+Enter runs it too.

How it's made

      

        Prismora is written once, in
        Temper, a language built for
        writing libraries that compile to many other languages. Temper turns
        the same source into a natural library for each one: classes and
        methods in C# and Java, modules in Lua and Python, a crate in Rust,
        and so on. Tests run on every language.
