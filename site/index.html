Prismora

Color math for every language. Convert between color spaces, parse any CSS color, fit colors to a screen's gamut, and mix them the way CSS Color 4 and 5 do, from C++, C#, Java, JavaScript, Lua, Python or Rust.

Try it

Type any CSS color: a name, hex, rgb(), hsl(), oklch(), color(display-p3 …) and more.

This color is outside sRGB, the range most screens and the web assume. On a wide-gamut screen, the first swatch shows it as written. The second shows the closest sRGB color, found the way CSS does: keeping lightness and hue, and reducing only chroma (colorfulness).

The same color in every space

A color space is a way to describe colors with numbers. Each one suits a different job. Prismora's numbers run from 0 to 1, with hue in turns (0 to 1) rather than degrees; the CSS column shows each space as CSS writes it.

How it's made

      

        Prismora is written once, in
        Temper, a language built for
        writing libraries that compile to many other languages. Temper turns
        the same source into a natural library for each one: classes and
        methods in Java and C#, modules in Python and Lua, a crate in Rust,
        and so on. Tests run on every language.
